# Сверка ПРО 2.0

Нативное Android-приложение для сравнения актов сверки в XLS, XLSX и CSV.

## Что изменилось

- Kivy, Python-for-Android, SDL и набор последовательных patch-скриптов удалены.
- Интерфейс, чтение таблиц, сверка и формирование отчёта работают на Java/Android SDK.
- XLSX читается без распаковки на диск; XLS — компактным OLE2/BIFF-ридером без тяжёлых офисных библиотек.
- Документы сопоставляются через индексы номера, суммы и даты без полного квадратичного перебора.
- Аварийные отчёты автоматически сохраняются в `Загрузки/Сверка_PRO`.
- Журнал содержит только технические этапы и стек исключения, без содержимого актов и сумм.

## Сборка

GitHub Actions запускает тест движка на 2500 + 2500 документов, собирает APK и проверяет отображение результата на Android-эмуляторе.
